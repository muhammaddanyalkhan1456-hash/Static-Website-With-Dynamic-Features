STATIC WEBSITE ASSIGNMENT
=========================

Project: Personal Portfolio Website
Deadline shown in assignment: 14-10-2026

FILES
- index.html: website content and sections
- style.css: layout, responsive design, colors, dark theme styling
- script.js: JavaScript interactions

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it in Chrome/Firefox.
4. Internet is only needed for the optional Google Fonts import; the website itself runs locally.

INTERACTIVE / DYNAMIC FEATURES
1. Dark mode / light mode button.
2. Responsive mobile navigation menu.
3. Project detail pop-up dialogs.
4. Contact form validation (client-side demo; it does not send emails or store data).
5. Automatically updates the footer year.

CUSTOMIZE BEFORE SUBMISSION
- Replace "Your Name" and "YN" with your own name/initials.
- Replace your.email@example.com with your email.
- Adjust the about section and skills to match your real details.
- Add your course/department/instructor details if your teacher requires them.

ASSIGNMENT DESCRIPTION
Create a static website with a little bit of dynamic features (user interaction).
This project uses HTML for structure, CSS for visual design and responsive layout, and JavaScript for interaction.
